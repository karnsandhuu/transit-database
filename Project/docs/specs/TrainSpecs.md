# Train Service Function Specifications

## `insertTrainModel()`

### Purpose

Creates a new train model in the `TrainModel` table.

### Function Signature

```javascript
async function insertTrainModel(
    modelName,
    numberOfCars
)
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `modelName` | String | Unique name identifying the train model. |
| `numberOfCars` | Number | Number of cars in the train model. Must be greater than 0. |

### Returns

Returns an object indicating whether the train model was successfully inserted.

#### Success

```javascript
{
    success: true,
    modelName
}
```

#### Failure

```javascript
{
    success: false
}
```

### Database Operation

Inserts a new record into `TrainModel`:

```sql
INSERT INTO TrainModel
(
    ModelName,
    NumberOfCars
)
VALUES
(
    :modelName,
    :numberOfCars
)
```

The transaction is automatically committed.

## `insertSubwayTrain()`

### Purpose

Registers a new subway train in the `SubwayTrain` table. The system automatically generates a unique `VehicleID` for the train.

### Function Signature

```javascript
async function insertSubwayTrain(
    trainSetNumber,
    modelName,
    manufactureYear,
    capacity,
    wheelchairAccessibility
)
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `trainSetNumber` | String | Unique identifier for the train set. |
| `modelName` | String | Name of an existing train model. |
| `manufactureYear` | Number | Year the train was manufactured. |
| `capacity` | Number | Maximum passenger capacity of the train. Must be greater than 0. |
| `wheelchairAccessibility` | String | Indicates wheelchair accessibility. Must be `Y` or `N`. |

### Returns

#### Success

```javascript
{
    success: true,
    vehicleId
}
```

The returned `vehicleId` is automatically generated by the system.

#### Failure

```javascript
{
    success: false
}
```

### Database Operation

Inserts a new record into `SubwayTrain`:

```sql
INSERT INTO SubwayTrain
(
    VehicleID,
    TrainSetNumber,
    ModelName,
    ManufactureYear,
    Capacity,
    WheelchairAccessibility
)
VALUES
(
    :vehicleId,
    :trainSetNumber,
    :modelName,
    :manufactureYear,
    :capacity,
    :wheelchairAccessibility
)
```

The transaction is automatically committed.

### ID Generation

`VehicleID` is generated sequentially using the existing maximum `VehicleID`.

If no subway trains exist:

```text
V000000001
```

If the current maximum is:

```text
V000000015
```

the next generated ID is:

```text
V000000016
```

## `getSubwayTrainByTrainSetNumber()`

### Purpose

Retrieves information about a subway train using its unique train-set number.

The function also retrieves information about the train's model and any routes that the train is registered to operate on.

### Function Signature

```javascript
async function getSubwayTrainByTrainSetNumber(
    trainSetNumber
)
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `trainSetNumber` | String | Unique train-set number of the subway train. |

### Returns

If the train exists, returns an object containing the train's information:

```javascript
{
    vehicleId,
    trainSetNumber,
    modelName,
    numberOfCars,
    manufactureYear,
    capacity,
    wheelchairAccessibility,
    routeNumbers
}
```

### Return Fields

| Field | Type | Description |
|---|---|---|
| `vehicleId` | String | Unique system-generated vehicle ID. |
| `trainSetNumber` | String | Unique train-set number. |
| `modelName` | String | Name of the train model. |
| `numberOfCars` | Number | Number of cars specified by the train model. |
| `manufactureYear` | Number | Year the train was manufactured. |
| `capacity` | Number | Maximum passenger capacity. |
| `wheelchairAccessibility` | String | `Y` if wheelchair accessible, otherwise `N`. |
| `routeNumbers` | Array | Route numbers that the train is currently registered to operate on. |

### Example

```javascript
{
    vehicleId: "V000000001",
    trainSetNumber: "TRAIN-001",
    modelName: "SkyTrainMarkIII",
    numberOfCars: 6,
    manufactureYear: 2022,
    capacity: 400,
    wheelchairAccessibility: "Y",
    routeNumbers: [99, 100]
}
```

If the train is not registered to any route:

```javascript
{
    vehicleId: "V000000001",
    trainSetNumber: "TRAIN-001",
    modelName: "SkyTrainMarkIII",
    numberOfCars: 6,
    manufactureYear: 2022,
    capacity: 400,
    wheelchairAccessibility: "Y",
    routeNumbers: []
}
```

If no train exists with the specified train-set number, the function returns:

```javascript
null
```

### Database Operation

The function joins `SubwayTrain` with `TrainModel` to obtain model information and uses `RunsOn` and `Route` to retrieve registered routes.

```sql
SELECT
    st.VehicleID,
    st.TrainSetNumber,
    st.ModelName,
    tm.NumberOfCars,
    st.ManufactureYear,
    st.Capacity,
    st.WheelchairAccessibility,
    r.RouteNumber
FROM SubwayTrain st
JOIN TrainModel tm
    ON st.ModelName = tm.ModelName
LEFT JOIN RunsOn ro
    ON st.VehicleID = ro.VehicleID
LEFT JOIN Route r
    ON ro.RouteID = r.RouteID
WHERE st.TrainSetNumber = :trainSetNumber
ORDER BY r.RouteNumber
```

The `LEFT JOIN` on `RunsOn` allows trains that are not currently registered on a route to still be returned.

## `registerTrainOnRoute()`

### Purpose

Registers an existing subway train as operating on an existing route.

This creates a relationship between a subway train and a route through the `RunsOn` table.

### Function Signature

```javascript
async function registerTrainOnRoute(
    vehicleId,
    routeId
)
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `vehicleId` | String | Vehicle ID of the subway train to register. |
| `routeId` | String | Route ID of the route the train will operate on. |

### Returns

#### Success

```javascript
{
    success: true,
    vehicleId,
    routeId
}
```

#### Failure

```javascript
{
    success: false
}
```

### Database Operation

Inserts a new relationship into `RunsOn`:

```sql
INSERT INTO RunsOn
(
    VehicleID,
    RouteID
)
VALUES
(
    :vehicleId,
    :routeId
)
```

The transaction is automatically committed.

### Constraints

The operation will fail if:

- The specified `vehicleId` does not exist.
- The specified `routeId` does not exist.
- The train is already registered on the specified route.

The last condition is enforced by the composite primary key:

```text
(VehicleID, RouteID)
```

# Exported Functions

The following functions are publicly exported by `trainService.js`:

| Function | Description |
|---|---|
| `insertTrainModel()` | Creates a new train model. |
| `insertSubwayTrain()` | Registers a new subway train and generates its `VehicleID`. |
| `getSubwayTrainByTrainSetNumber()` | Retrieves a subway train, its model information, and registered route numbers. |
| `registerTrainOnRoute()` | Registers a subway train on a route. |
