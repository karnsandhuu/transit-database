# Station Service Function Specifications

## Overview

The `stationService` module provides services for managing **zones** and **transport stations**.

The service is responsible for:

- Registering zones.
- Retrieving individual zones.
- Retrieving all zones.
- Registering transport stations.
- Automatically generating station IDs.
- Retrieving individual stations.
- Retrieving all stations.
- Retrieving all stations within a specific zone.

The service uses the Oracle database through the `withOracleDB` database utility.

---

# Zone Services

## `insertZone()`

### Purpose

Registers a new zone in the database.

### Function Signature

```javascript
async function insertZone(
    zoneNumber,
    zoneName,
    colour = null,
    zoneDescription = null
)
```

### Parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `zoneNumber` | Number | Yes | Unique identifier for the zone. |
| `zoneName` | String | Yes | Name of the zone. |
| `colour` | String | No | Colour associated with the zone. Defaults to `null`. |
| `zoneDescription` | String | No | Description of the zone. Defaults to `null`. |

### Database Operation

Inserts a new tuple into the `Zone` table.

```text
Zone(
    ZoneNumber,
    ZoneName,
    Colour,
    ZoneDescription
)
```

### Return Value

#### Successful insertion

```javascript
{
    success: true,
    zoneNumber
}
```

#### Failed insertion

```javascript
{
    success: false
}
```

### Failure Conditions

The function returns `success: false` if the database insertion fails.

Possible database errors include:

- Duplicate `ZoneNumber`.
- Invalid foreign key relationships, if applicable.
- Constraint violations.
- Database connection errors.

The error is logged to the console.

## `getZoneById()`

### Purpose

Retrieves a single zone using its zone number.

### Function Signature

```javascript
async function getZoneById(zoneNumber)
```

### Parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `zoneNumber` | Number | Yes | Zone number used to identify the zone. |

### Database Operation

Searches the `Zone` table for a tuple whose `ZoneNumber` matches the supplied value.

### Return Value

If the zone exists:

```javascript
{
    zoneNumber: 1,
    zoneName: "Downtown",
    colour: "Red",
    zoneDescription: "Central transit zone"
}
```

If the zone does not exist:

```javascript
null
```

If a database error occurs:

```javascript
null
```

---

## `getAllZones()`

### Purpose

Retrieves all zones registered in the database.

### Function Signature

```javascript
async function getAllZones()
```

### Parameters

None.

### Database Operation

Retrieves all tuples from the `Zone` table and orders them by `ZoneNumber` in ascending order.

### Return Value

Returns an array of zone objects.

Example:

```javascript
[
    {
        zoneNumber: 1,
        zoneName: "Downtown",
        colour: "Red",
        zoneDescription: "Central transit zone"
    },
    {
        zoneNumber: 2,
        zoneName: "West",
        colour: "Blue",
        zoneDescription: "Western transit zone"
    }
]
```

If no zones exist, an empty array is returned:

```javascript
[]
```

If a database error occurs, an empty array is returned.

# Station Services

## `insertStation()`

### Purpose

Registers a new transport station and automatically generates its station ID.

### Function Signature

```javascript
async function insertStation(
    zoneNumber,
    stationName,
    address,
    wheelchairAccessibility
)
```

### Parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `zoneNumber` | Number | Yes | Zone containing the station. |
| `stationName` | String | Yes | Name of the station. |
| `address` | String | Yes | Physical address of the station. |
| `wheelchairAccessibility` | String | Yes | Indicates whether the station is wheelchair accessible. Expected values are `Y` or `N`. |

### Station ID Generation

The station ID is automatically generated by `generateStationID()`.

The first station receives:

```text
S000000001
```

Subsequent stations increment the numeric portion:

```text
S000000002
S000000003
S000000004
...
```

The client therefore does not provide a station ID.

### Database Operation

Inserts a new tuple into `TransportStation`.

```text
TransportStation(
    StationID,
    ZoneNumber,
    StationName,
    Address,
    WheelchairAccessibility
)
```

### Return Value

#### Successful insertion

```javascript
{
    success: true,
    stationId: "S000000001"
}
```

#### Failed insertion

```javascript
{
    success: false
}
```

### Failure Conditions

The function returns `success: false` if the insertion fails.

Possible causes include:

- The specified zone does not exist.
- Invalid wheelchair accessibility value.
- Database constraint violation.
- Database connection error.

## `generateStationID()`

### Purpose

Generates a unique sequential station ID.

This is an internal helper function and is **not exported** by `stationService`.

### Function Signature

```javascript
async function generateStationID(connection)
```

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `connection` | Oracle Connection | Active Oracle database connection. |

### Operation

The function retrieves the largest existing `StationID`:

```sql
SELECT MAX(StationID)
FROM TransportStation
```

If no stations exist, it returns:

```text
S000000001
```

Otherwise, it:

1. Removes the `S` prefix.
2. Converts the remaining number to an integer.
3. Increments the number by one.
4. Pads the number to nine digits.
5. Adds the `S` prefix.

For example:

```text
S000000007
```

becomes:

```text
S000000008
```

### Return Value

A newly generated station ID.

Example:

```javascript
"S000000008"
```

## `getStationsByZone()`

### Purpose

Retrieves all transport stations belonging to a specified zone.

### Function Signature

```javascript
async function getStationsByZone(zoneNumber)
```

### Parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `zoneNumber` | Number | Yes | Zone number whose stations should be retrieved. |

### Database Operation

Retrieves all stations from `TransportStation` whose `ZoneNumber` matches the supplied zone number.

Results are ordered by `StationID` in ascending order.

### Return Value

Returns an array of station objects.

Example:

```javascript
[
    {
        stationId: "S000000003",
        zoneNumber: 2,
        stationName: "West Station",
        address: "456 West Avenue",
        wheelchairAccessibility: "Y"
    },
    {
        stationId: "S000000004",
        zoneNumber: 2,
        stationName: "Central West Station",
        address: "789 West Road",
        wheelchairAccessibility: "N"
    }
]
```

If no stations belong to the specified zone:

```javascript
[]
```

If a database error occurs:

```javascript
[]
```

# Exported Functions

The following functions are exported by `stationService`:

```javascript
module.exports = {
    insertZone,
    getZoneById,
    getAllZones,
    insertStation,
    getStationById,
    getAllStations,
    getStationsByZone
};
```

| Function | Purpose | Return Type |
|---|---|---|
| `insertZone()` | Register a zone | Object |
| `getZoneById()` | Retrieve one zone | Object / `null` |
| `getAllZones()` | Retrieve all zones | Array |
| `insertStation()` | Register a station | Object |
| `getStationById()` | Retrieve one station | Object / `null` |
| `getAllStations()` | Retrieve all stations | Array |
| `getStationsByZone()` | Retrieve stations in a zone | Array |

## Internal Functions

| Function | Purpose | Exported |
|---|---|---|
| `generateStationID()` | Generate the next sequential station ID | No |

# Error Handling

All database operations are performed through `withOracleDB()`.

Database errors are caught inside each service function and logged to the console.

The service does not expose database error details to callers. Instead, it returns a safe failure value:

- Insert operations return `{ success: false }`.
- Single-record retrieval operations return `null`.
- List retrieval operations return `[]`.

This keeps database-specific errors inside the service layer and provides predictable return values to controllers.
