# Passenger Service Function Specifications

The `passengerService` module provides database operations for managing passengers. It is responsible for creating, retrieving, and updating passenger records.

**File:** `services/passengerService.js`

---

## `insertPassenger()`

### Purpose

Creates a new passenger in the `Passenger` table.

The `PassengerID` is generated automatically by the service and is not provided by the client.

### Parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `firstName` | String | Yes | Passenger's first name |
| `lastName` | String | Yes | Passenger's last name |
| `passengerType` | String | No | Passenger category. Defaults to `"Adult"` |

Valid passenger categories are:

- `Adult`
- `Child`
- `Senior`
- `Student`

### Example

```javascript
const result = await insertPassenger(
    "John",
    "Smith",
    "Student"
);
```

If `passengerType` is omitted:

```javascript
const result = await insertPassenger(
    "John",
    "Smith"
);
```

The passenger type defaults to:

```text
Adult
```

### Return Value

#### Successful insertion

```javascript
{
    success: true,
    passengerId: "P000000001"
}
```

The generated `passengerId` is returned to the caller.

#### Failed insertion

```javascript
{
    success: false
}
```

### Notes

- `PassengerID` is generated automatically.
- The generated ID follows the format `P#########`.
- The first passenger receives `P000000001`.
- Subsequent passenger IDs are generated by incrementing the numeric portion of the largest existing ID.
- The database insert is committed automatically.

## `generatePassengerID()`

### Purpose

Generates a unique passenger ID for a new passenger.

This is an internal helper function and is not exported from `passengerService`.

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `connection` | Oracle Connection | Active Oracle database connection |

### Return Value

Returns a string containing the generated passenger ID.

Example:

```text
P000000001
```

If the largest existing ID is:

```text
P000000005
```

the generated ID is:

```text
P000000006
```

### Notes

- The first character is `P`.
- The remaining nine characters are zero-padded digits.
- Maximum length is 10 characters, matching the `PassengerID VARCHAR2(10)` column.

## `getPassengerById()`

### Purpose

Retrieves a single passenger using their unique passenger ID.

### Parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `passengerId` | String | Yes | Unique ID of the passenger |

### Example

```javascript
const passenger = await getPassengerById(
    "P000000001"
);
```

### Return Value

If the passenger exists:

```javascript
{
    passengerId: "P000000001",
    firstName: "John",
    lastName: "Smith",
    passengerType: "Adult"
}
```

If the passenger does not exist:

```javascript
null
```

If a database error occurs:

```javascript
null
```

### Notes

`PassengerID` is the primary key of the `Passenger` table and is therefore used to uniquely identify the passenger.

---

## `getAllPassengers()`

### Purpose

Retrieves all passengers currently stored in the `Passenger` table.

### Parameters

None.

### Example

```javascript
const passengers = await getAllPassengers();
```

### Return Value

Returns an array of passenger objects.

Example:

```javascript
[
    {
        passengerId: "P000000001",
        firstName: "John",
        lastName: "Smith",
        passengerType: "Adult"
    },
    {
        passengerId: "P000000002",
        firstName: "Alice",
        lastName: "Brown",
        passengerType: "Student"
    }
]
```

If no passengers exist:

```javascript
[]
```

If a database error occurs:

```javascript
[]
```

### Notes

The function explicitly selects the following attributes:

```text
PassengerID
FirstName
LastName
PassengerCategory
```

---

## `updatePassengerType()`

### Purpose

Updates the passenger category of an existing passenger.

### Parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `passengerId` | String | Yes | ID of the passenger to update |
| `passengerType` | String | Yes | New passenger category |

Valid passenger categories are:

- `Adult`
- `Child`
- `Senior`
- `Student`

### Example

```javascript
const success = await updatePassengerType(
    "P000000001",
    "Student"
);
```

### Return Value

If the passenger is successfully updated:

```javascript
true
```

If no passenger with the specified ID exists:

```javascript
false
```

If a database error occurs:

```javascript
false
```

### Notes

- Only `PassengerCategory` is modified.
- `PassengerID`, `FirstName`, and `LastName` remain unchanged.
- The update is committed automatically.
- The `PassengerID` is used to identify the passenger being updated.

## Function Summary

| Function | Purpose | Parameters | Return |
|---|---|---|---|
| `insertPassenger()` | Create passenger | `firstName`, `lastName`, `passengerType?` | `{ success, passengerId }` |
| `generatePassengerID()` | Generate passenger ID | `connection` | `String` |
| `getPassengerById()` | Find one passenger | `passengerId` | Passenger object / `null` |
| `getAllPassengers()` | Find all passengers | None | Passenger array |
| `updatePassengerType()` | Change passenger category | `passengerId`, `passengerType` | `Boolean` |

### Service Responsibilities

`passengerService` is responsible for:

1. Performing passenger-related database operations.
2. Generating passenger IDs.
3. Validating successful database operations through their return values.
4. Converting database rows into JavaScript passenger objects.
5. Handling database errors without exposing raw database errors to the client.
