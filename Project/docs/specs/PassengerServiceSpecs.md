# Passenger Service Function Specifications

The `passengerService` module provides database operations for managing passengers. It is responsible for creating, retrieving, and updating passenger records.

**File:** `services/passengerService.js`

---

## `insertPassenger()`

### Purpose

Creates a new passenger in the `Passenger` table.

The `PassengerID` is generated automatically by the service and is not provided by the client.

### Parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `firstName` | String | Yes | Passenger's first name |
| `lastName` | String | Yes | Passenger's last name |
| `passengerType` | String | No | Passenger category. Defaults to `"Adult"` |

Valid passenger categories are:

- `Adult`
- `Child`
- `Senior`
- `Student`

### Example

```javascript
const result = await insertPassenger(
    "John",
    "Smith",
    "Student"
);
```

If `passengerType` is omitted:

```javascript
const result = await insertPassenger(
    "John",
    "Smith"
);
```

The passenger type defaults to:

```text
Adult
```

### Return Value

#### Successful insertion

```javascript
{
    success: true,
    passengerId: "P000000001"
}
```

The generated `passengerId` is returned to the caller.

#### Failed insertion

```javascript
{
    success: false
}
```

### Notes

- `PassengerID` is generated automatically.
- The generated ID follows the format `P#########`.
- The first passenger receives `P000000001`.
- Subsequent passenger IDs are generated by incrementing the numeric portion of the largest existing ID.
- The database insert is committed automatically.

## `generatePassengerID()`

### Purpose

Generates a unique passenger ID for a new passenger.

This is an internal helper function and is not exported from `passengerService`.

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `connection` | Oracle Connection | Active Oracle database connection |

### Return Value

Returns a string containing the generated passenger ID.

Example:

```text
P000000001
```

If the largest existing ID is:

```text
P000000005
```

the generated ID is:

```text
P000000006
```

### Notes

- The first character is `P`.
- The remaining nine characters are zero-padded digits.
- Maximum length is 10 characters, matching the `PassengerID VARCHAR2(10)` column.

## `getPassengerById()`

### Purpose

Retrieves a single passenger using their unique passenger ID.

The function supports **projection**, allowing the caller to specify which passenger attributes should be returned and the order in which they should be retrieved.

### Parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `passengerId` | String | Yes | Unique ID of the passenger |
| `attributes` | Array of Strings | No | Attributes to retrieve, in the desired order. If omitted, all supported attributes are returned in the default order. |

### Supported Attributes

| Attribute | Database Column | Description |
|---|---|---|
| `passengerId` | `PassengerID` | Unique ID of the passenger |
| `firstName` | `FirstName` | Passenger's first name |
| `lastName` | `LastName` | Passenger's last name |
| `passengerCategory` | `PassengerCategory` | Passenger's category |

### Default Attributes

If `attributes` is not provided, the function retrieves:

```javascript
[
    "passengerId",
    "firstName",
    "lastName",
    "passengerCategory"
]
```

### Example

Retrieve all passenger attributes:

```javascript
const passenger = await getPassengerById(
    "P000000001"
);
```

Example return value:

```javascript
{
    passengerId: "P000000001",
    firstName: "John",
    lastName: "Smith",
    passengerCategory: "Adult"
}
```

### Projection Example

The caller can specify a subset of attributes:

```javascript
const passenger = await getPassengerById(
    "P000000001",
    [
        "lastName",
        "passengerId"
    ]
);
```

The function generates a query that retrieves only the requested attributes:

```sql
SELECT LastName, PassengerID
FROM Passenger
WHERE PassengerID = :passengerId
```

The returned object contains only the selected attributes:

```javascript
{
    lastName: "Smith",
    passengerId: "P000000001"
}
```

### Attribute Ordering

The attributes are retrieved from the database in the same order as specified in the `attributes` array.

For example:

```javascript
const passenger = await getPassengerById(
    "P000000001",
    [
        "passengerCategory",
        "lastName",
        "passengerId"
    ]
);
```

results in a query equivalent to:

```sql
SELECT PassengerCategory, LastName, PassengerID
FROM Passenger
WHERE PassengerID = :passengerId
```

The returned object follows the requested attribute order:

```javascript
{
    passengerCategory: "Adult",
    lastName: "Smith",
    passengerId: "P000000001"
}
```

### Invalid Attributes

If an attribute that is not supported is provided, the function throws an error.

Example:

```javascript
await getPassengerById(
    "P000000001",
    [
        "lastName",
        "invalidAttribute"
    ]
);
```

The function throws:

```text
Invalid passenger attribute: invalidAttribute
```

### Empty Attribute List

If an empty attribute array is provided:

```javascript
await getPassengerById(
    "P000000001",
    []
);
```

the function returns:

```javascript
null
```

### Return Value

If the passenger exists, returns a passenger object containing the requested attributes.

If the passenger does not exist:

```javascript
null
```

If a database error occurs:

```javascript
null
```

### Notes

- `PassengerID` is the primary key of the `Passenger` table and is used to uniquely identify the passenger.
- Only attributes included in the `attributes` array are retrieved from the database.
- The order of the attributes in the generated SQL query follows the order specified by the caller.
- Attribute names are validated against a predefined list of supported attributes before being included in the SQL query.
- This validation prevents arbitrary user input from being inserted into the SQL `SELECT` clause.

## `getAllPassengers()`

### Purpose

Retrieves all passengers currently stored in the `Passenger` table.

### Parameters

None.

### Example

```javascript
const passengers = await getAllPassengers();
```

### Return Value

Returns an array of passenger objects.

Example:

```javascript
[
    {
        passengerId: "P000000001",
        firstName: "John",
        lastName: "Smith",
        passengerCategory: "Adult"
    },
    {
        passengerId: "P000000002",
        firstName: "Alice",
        lastName: "Brown",
        passengerCategory: "Student"
    }
]
```

If no passengers exist:

```javascript
[]
```

If a database error occurs:

```javascript
[]
```

### Notes

The function explicitly selects the following attributes:

```text
PassengerID
FirstName
LastName
PassengerCategory
```

Unlike `getPassengerById()`, `getAllPassengers()` does not currently support user-selected projection.

## `updatePassengerType()`

### Purpose

Updates the passenger category of an existing passenger.

### Parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `passengerId` | String | Yes | ID of the passenger to update |
| `passengerType` | String | Yes | New passenger category |

Valid passenger categories are:

- `Adult`
- `Child`
- `Senior`
- `Student`

### Example

```javascript
const success = await updatePassengerType(
    "P000000001",
    "Student"
);
```

### Return Value

If the passenger is successfully updated:

```javascript
true
```

If no passenger with the specified ID exists:

```javascript
false
```

If a database error occurs:

```javascript
false
```

### Notes

- Only `PassengerCategory` is modified.
- `PassengerID`, `FirstName`, and `LastName` remain unchanged.
- The update is committed automatically.
- The `PassengerID` is used to identify the passenger being updated.

## Function Summary

| Function | Purpose | Parameters | Return |
|---|---|---|---|
| `insertPassenger()` | Create passenger | `firstName`, `lastName`, `passengerType?` | `{ success, passengerId }` |
| `generatePassengerID()` | Generate passenger ID | `connection` | `String` |
| `getPassengerById()` | Find one passenger | `passengerId` | Passenger object / `null` |
| `getAllPassengers()` | Find all passengers | None | Passenger array |
| `updatePassengerType()` | Change passenger category | `passengerId`, `passengerType` | `Boolean` |

### Service Responsibilities

`passengerService` is responsible for:

1. Performing passenger-related database operations.
2. Generating passenger IDs.
3. Validating successful database operations through their return values.
4. Converting database rows into JavaScript passenger objects.
5. Handling database errors without exposing raw database errors to the client.
